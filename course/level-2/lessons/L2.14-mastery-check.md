# L2.14 — Level 2 Mastery Check

**Goal:** Confirm the learner has met every Level 2 exit criterion before starting
Level 3.
**New today:** nothing — this is the gate, not a teaching lesson.
**Review:** everything from L2.01–L2.13.
**Heart words:** none new (all 29 already taught).
**Time:** 25–35 min, can be split across two sittings if needed (DESIGN.md rule 10).
**Materials:** paper, pencil; the full instrument lives in
`course/level-2/mastery-check.md` — use that document, not this page, to actually
run the check. This lesson file exists only so L2.14 has an entry in the lesson
sequence matching the master scope-and-sequence in DESIGN.md §3.

## Why this is a separate document
A real exit gate needs more than the 9-step lesson template can hold in one sitting:
real-word and pseudoword lists across all 12 taught patterns, a full dictation
including a sentence, both Track A and Track B comprehension passages, a
heart-word check of all 29 words, and an explicit pass/fail routing table. Putting
all of that inside a normal lesson page would blow past the 20–35 minute lesson
format this level has used throughout. `mastery-check.md` is built to be printed or
opened on its own, administered once, and scored against the same ≥90% bar used at
every Check step in every lesson before it (DESIGN.md rule 4).

## What to do
1. Confirm L2.13's Check step scored ≥90%. If not, do not attempt this mastery
   check yet — go back to `L2.13-review.md`'s reteach instruction first.
2. Open `course/level-2/mastery-check.md` and administer it exactly as written.
3. Score it using the pass/fail table in that document.
4. **Pass (≥90% on every component)** → the learner starts Level 3 at `L3.01`.
5. **Fail on one or more components** → the document names exactly which Level 2
   lesson(s) to re-run before re-testing only the failed component(s) — never the
   whole instrument from scratch, and never by calendar (DESIGN.md rule 4).

## Tutor notes
- Do not coach, hint, or hand out cueing strategies during the check itself
  (DESIGN.md rule 1) — this is an honest measurement, not a teaching moment. Teach
  again, generously, afterward if needed.
- Comprehension and decoding are scored and reported **separately** — a learner can
  decode at 95% and comprehend at 70%, and that is a real, useful, actionable
  result, not a single blended score (DESIGN.md rule 8).
- For adults: frame the check exactly as it is — a checkpoint that unlocks the next
  set of skills, not a test they can "fail" as a person. Zero penalty for retaking
  after a reteach (DESIGN.md rule 10).
