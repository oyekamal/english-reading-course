# L3.18 — Level 3 Mastery Check

**Goal:** Administer the graded Level 3 exit assessment and decide: advance to Level 4, or return to a specific lesson for reteaching.
**New today:** none — this is the assessment session
**Review:** the full instrument is in `../mastery-check.md`; this file is the short tutor script for running it in one sitting.
**Heart words:** all 16, tested
**Time:** 25–30 min (assessment only — no new teaching)
**Materials:** `mastery-check.md` (printed or on screen), paper, pencil, a stopwatch or phone timer

## 1. Warm-up (2 min)
No teaching today. Tell the learner plainly: "Today we check everything you've learned in this level. Do your best — if something is hard, that just tells us what to practice next, it's not a test you can fail."

## 2. Run the instrument (18–20 min)
Follow `mastery-check.md` in order:
1. Heart-word flash (16 words)
2. Real-word reading list (20 words, one per Level 3 pattern + a couple of repeats for the hardest families: VCe, oo, -ild/-ind/-old/-ost)
3. Pseudoword reading list (10 words)
4. Dictation (8 items: 5 words + 1 sentence + 2 heart words)
5. Connected-text reading with WCPM + prosody check (the Level 3 exit passage, ~180 words)
6. Two comprehension questions (literal) + one flex-decode narration question ("Tell me what you did when you weren't sure how to read a word like ___")

## 3. Score it (5 min)
Use the scoring table and decision rule in `mastery-check.md` §4. Record the result in the learner's own log (a simple dated line is enough: date, % correct on real+pseudo words, WCPM, pass/reteach decision).

## 4. Decide and act
- **Passed (≥90% decoding, comprehension answers correct, flex-routine narrated correctly at least once):** learner is ready for Level 4 (The Full Code). Note their WCPM figure — it becomes the learner's own baseline for Level 4's fluency tracking (there is no external norm table for this stage; see Level 3 README §Fluency routine).
- **Below 90% on real+pseudo words, in one or two specific families:** return to those specific lesson(s) only (e.g., missed everything in the -ild/-ind/-old/-ost set → reteach L3.16 only), then re-run just that section of the mastery check, not the whole instrument.
- **Below 90% and errors are spread across many families, not concentrated:** return to L3.17 (Review) for another full pass before re-attempting the complete mastery check.
- **Comprehension questions wrong but decoding was strong:** this is a decoding/comprehension mismatch — flag it, do not advance silently; add extra Listen & Talk practice and re-check comprehension specifically before moving on (never report decoding success as if it were comprehension success — DESIGN.md Rule 8).

## Tutor notes
- Do not cue during the assessment, even more strictly than during teaching — no hints, no "look at the first letter," no repeating a word in a leading tone. Silence after a wrong attempt, then move on, is correct.
- If the learner is anxious about the word "check" or "test," rename it in your own words — "let's see what you've got so far" — the instrument doesn't require the word "test" to be used with the learner.
- For adult learners: let them see their own WCPM number and explain plainly it's their own personal baseline, not a comparison to any child-normed table (per the fluency-routine note in the Level 3 README) — this avoids demoralizing a learner with a norm that was never meant for them.
